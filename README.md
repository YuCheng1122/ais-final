# AIS3 CTF step-extraction scoring pipeline

Scores LLM agent CTF solve transcripts against official reference writeups,
using a shared `ctf-step` JSON schema for both. Two independent signals:

- **Anchor matching** (decisive): does the agent's own text contain the
  literal tokens (`anchors[]`) a ground-truth step requires? This is the only
  signal that decides whether a step counts as "reached."
- **Milestone-embedding similarity** (exploratory, local, Qwen3-Embedding-0.6B):
  did the agent's own step milestones look semantically close to a
  ground-truth step? Shown for context only, never used to decide reached-ness
  — a model can describe the right idea while being on a completely wrong
  path.

See the module docstrings in `src/score_steps.py` and `src/anchor_match.py`
for the exact matching rules, and `src/METHODOLOGY.md` for a short summary.

## Data layout

```text
Dataset/
  README.md / INDEX.md / PROMPT.md   # dataset provenance + extraction spec
  json/<challenge>/reference.json
  json/<challenge>/agent/<solver>/run-XX.json
  writeups/<challenge>/reference.md
  writeups/<challenge>/agent/<solver>.md
```

`<challenge>` is the Dataset folder name (e.g. `C01_crypto_ROT13`) — the
`C`/`R`/`D` prefix means Contaminated/Recent/Deep (data-provenance grouping,
independent of topic). This is the canonical challenge id used by
`score_steps.py`/`render_table.py`; the JSON's own internal `"challenge"`
field (e.g. `crypto_picoctf5`) predates this layout and is kept only as
`challenge_slug` metadata.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` currently pins the **CPU-only** torch wheel
(`torch==2.13.0+cpu`). The embedding pass (Qwen3-Embedding-0.6B, ~942 agent
runs) is noticeably slow on CPU. To run on GPU instead, install a
CUDA-enabled torch build matching your driver/GPU before installing the rest
of `requirements.txt` — `sentence-transformers` picks up CUDA automatically
if `torch.cuda.is_available()`.

## Running

```bash
python3 src/score_steps.py                 # score all challenges (anchors + semantic)
python3 src/score_steps.py --no-semantic    # anchor-only, much faster
python3 src/score_steps.py --challenge C01_crypto_ROT13
python3 src/render_table.py                 # -> output/step_scores_table.html
```

`output/` is git-ignored (regenerated by the two commands above).
