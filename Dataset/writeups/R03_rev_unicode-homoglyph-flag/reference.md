# Writeup — ooo (LACTF 2026, rev/easy)

## 辨識

`ooo.py` 定義了一堆函式，名稱都是視覺上相同的「o」同形字（Unicode homoglyph），
各自其實只是一個簡單的二元運算：

| 函式（同形字） | 運算 |
|---|---|
| `о` (U+043E) | `a + b` |
| `ο` (U+03BF) | `a - b` |
| `օ` (U+0585) | `a * b` |
| `ỏ` (U+1ECF) | `a // b` |
| `ơ` (U+01A1) | `a ^ b` (xor) |
| `ó` (U+00F3) | `a \| b` (or) |
| `ὀ` (U+1F40) | `a & b` (and) |
| `ὸ` (U+1F78) | `b - a` |
| `ὄ` (U+1F44) | `return a` |
| `ὂ` (U+1F42) | `return b` |
| `ȯ` (U+022F) | `a % b` |

目標陣列 `ὁ` (U+1F41)：

```
[205, 196, 215, 218, 225, 226, 1189, 2045, 2372, 9300, 8304, 660, 8243,
 16057, 16113, 16057, 16004, 16007, 16006, 8561, 805, 346, 195, 201, 154, 146, 223]
```

檢查器對輸入 `guess`（提示 flag 以 `lactf{` 開頭）逐位檢查，取 `a=ord(guess[i])`、
`b=ord(guess[i+1])`，判斷：

```python
о(ὄ(a,b), ὂ(a,b))  !=  ὁ[ ơ(i, ȯ(օ(a,b), a)) ]
```

## 化簡約束

- 左式 `о(ὄ(a,b), ὂ(a,b))` = `a + b`。
- 右式索引 `ơ(i, ȯ(օ(a,b), a))` = `i ^ ((a*b) % a)`。因為 `(a*b) % a == 0`，索引化簡為 `i ^ 0 = i`。

因此整個檢查等價於：**對所有 i，`ord(guess[i]) + ord(guess[i+1]) == arr[i]`**——
相鄰兩字元碼點相加要等於陣列對應項。

## 解法（望遠鏡式遞推）

flag 開頭為 `l`（`ord('l') = 108`）。從 `prev = 108` 出發，逐項推下一字元：
`next = arr[i] - prev`，即可還原整條字串（包含各同形字「o」的碼點）。

```python
arr = [205,196,215,218,225,226,1189,2045,2372,9300,8304,660,8243,
       16057,16113,16057,16004,16007,16006,8561,805,346,195,201,154,146,223]
prev = ord('l'); out = 'l'
for v in arr:
    prev = v - prev
    out += chr(prev)
print(out)   # == flag
```

推出的字串即為 flag，各「o」被還原成 Cyrillic/Greek/Armenian 等同形碼點。
