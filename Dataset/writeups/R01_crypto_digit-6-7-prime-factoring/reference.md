# Writeup — six-seven (LACTF 2026, crypto/medium)

## 辨識

服務端 `chall.py` 用 `generate_67_prime(256)` 產生質數：256 位十進位數，除最低位固定為 `7` 外，其餘每位皆從 `{6,7}` 隨機挑選。兩個這樣的質數相乘得 `n`，`e=65537`，`c=pow(m,e,n)`。這是標準 RSA，關鍵在於 `p`、`q` 的十進位數字被嚴格限制，可以從最低位開始逐位重建分解。

## 攻擊原理

設已重建出 `p` 的低位後綴 `test_p`（長度 `L`）。在候選前面補一位 `6` 或 `7` 得到 `test6 = int('6'+str(test_p))`、`test7 = int('7'+str(test_p))`。令 `modulo = 10^(L+1)`，計算：

```python
result = n * pow(testX, -1, modulo) % modulo
```

因為 `n = p*q`，故 `result` 恰為 `q` 在 `mod 10^(L+1)` 下應有的低位。若 `result` 每一位都是 `6` 或 `7` 且長度正確，代表這個前綴與「`q` 也是 67-質數」的條件相容，保留為候選；否則剪枝。用一個堆疊做分支定界（branch-and-prune），從後綴 `7` 開始逐位往前擴展，直到長度達 256 即得 `p`。

## 核心腳本

```python
p_stack = [7]
p = None
while p_stack:
    test_p = p_stack.pop()
    modulo = 10**(len(str(test_p)) + 1)
    for d in ('6', '7'):
        testX = int(d + str(test_p))
        result = n * pow(testX, -1, modulo) % modulo
        if all(i in '67' for i in str(result)) and len(str(result)) == len(str(testX)):
            p_stack.append(testX)
            if len(str(testX)) == 256:
                p = testX
```

取得 `p` 後 `q = n // p`，接著標準 RSA 解密：

```python
t = (p-1)*(q-1)
d = pow(65537, -1, t)
m = pow(c, d, n)
print(long_to_bytes(m))
```
